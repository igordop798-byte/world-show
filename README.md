# world-show

Прототип игры с захватом движений через веб-камеру. Работает целиком в браузере:
видео никуда не передаётся, всё считается на устройстве игрока.

**Играть:** https://igordop798-byte.github.io/world-show/

## Что уже есть

Сцена «Мост над пустотой» — бег от третьего лица по бесконечному мосту.

| Действие игрока | Что происходит |
|---|---|
| Топчешься на месте, поднимая колени | Бежишь вперёд, частота шагов задаёт скорость |
| Наклон корпуса влево/вправо | Шаг в сторону по мосту; за краем — пустота |
| Прыжок | Через барьеры и провалы в настиле |
| Присед | Под арками |
| Мах правой рукой | Удар мечом, засчитывается по скорости кончика клинка |
| Широко открыть рот | Боевой крик, сносит преграды впереди |

## Технологии

- **MediaPipe Pose Landmarker** — 33 точки скелета, включая 3D-координаты в метрах
  (`worldLandmarks`), на них строится риг аватара.
- **MediaPipe Face Landmarker** — 478 точек лица и 52 коэффициента мимики ARKit
  (открывание челюсти, улыбка, брови, моргание, взгляд) плюс матрица поворота головы.
- **Three.js** — рендер: атмосферное небо с рассеянием, карта окружения из неба для
  отражений в PBR-материалах, ACES-тонмаппинг, bloom, экспоненциальный туман.

Всё грузится с CDN, сборка не нужна.

## Запуск локально

Файл самодостаточный, но камере нужен защищённый источник. Либо открой `index.html`
двойным кликом в Chrome, либо, если браузер откажет:

```
python3 -m http.server 8000
```

и зайди на `http://localhost:8000`.

## Настройка под себя

В панели справа:

- **Калибровка** — обязательный первый шаг, снимает базовую стойку.
- **Развернуть аватара** — если видишь лицо вместо спины.
- **Инвертировать наклон** — если шаг в сторону идёт не туда.
- **Качество** — низкое/среднее/высокое, при просадке FPS понижается само.
- Клавиши `[` `]` — чувствительность шагов, `-` `=` — амплитуда бокового хода.
